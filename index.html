◆ Drill Core Repository Architecture & GitHub Publishing

⭐ Standalone Architecture

Every single lecture log in this archive is 100% self-contained. It contains zero external CSS/JS framework dependencies, uses vanilla JavaScript requestAnimationFrame for timecode tracking, and renders LaTeX math via KaTeX CDN.

⌨ Collapsible Navigation

Press [ or click Lectures in the top bar to toggle the directory sidebar. On widescreen displays, it smoothly docks to provide simultaneous side navigation; on mobile devices, it operates as an overlay drawer.
