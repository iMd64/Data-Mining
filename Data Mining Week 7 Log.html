Decision Tree Synthesis: Entropy, Information Gain & Overfitting

The professor conducts an in-depth review of tree-based induction to clarify why evaluation metrics are indispensable:

\[H(S) = - \sum_{i=1}^{c} p_i \log_2(p_i), \quad IG(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)\]

Key architectural takeaways reiterated by Dr. Bulut:

Algorithmic MechanismCore Operational PrincipleGeneralisation Vulnerability
Recursive SplittingPartitions feature space into axis-aligned rectangular hyper-rectangles by greedily maximising Information Gain.Favors high-cardinality attributes without gain ratio penalization.
Unbounded GrowthContinues splitting nodes until every terminal leaf is pure (\(H=0\)).Memorizes noise and outliers, resulting in severe overfitting.
Tree PruningCollapses non-significant subtrees using validation error thresholds.Critical for preserving test-set generalisation over training accuracy.

He underlines: An unpruned tree easily achieves 100% training accuracy. Thus, reporting training accuracy alone is scientifically invalid — proving the necessity of an independent evaluation paradigm.

Probabilistic & Instance-Based Foundations: Naive Bayes & KNN

Continuing the midterm synthesis, Dr. Bulut contrasts the structural inductive biases of probabilistic vs instance-based models:

Naive Bayes Classifier

  • Core Formulation\(P(C_k \mid \mathbf{x}) \propto P(C_k) \prod_{i=1}^d P(x_i \mid C_k)\)
  • AxiomConditional independence among features given the class label.
  • Zero PreventionLaplace estimator \(\frac{n_c + 1}{n + |V|}\) prevents probability collapse.

K-Nearest Neighbors (KNN)

  • Core Formulation\(\hat{y} = \arg\max_{c} \sum_{i \in N_k(\mathbf{x})} \mathbb{I}(y_i = c)\)
  • AxiomGeometric proximity in feature space determines class identity.
  • Distance ScaleEuclidean distance \(L_2\) mandates min-max or z-score feature normalization.

From Inference to Performance Evaluation: Regardless of whether predictions originate from a recursive decision tree, a probabilistic Bayesian posterior, or a geometric KNN query, the final output on test data is a set of predicted labels \(\hat{y}\). How do we objectively judge which model performs best? This introduces Week 7: Confusion Matrix and Performance Evaluation.

00:26:16 UBIS 00:26:16 to 00:30:45Slides 1–6

The Primacy of Measurement (*Mesura*) in Data Mining

Dr. Faruk Bulut formally commences the Week 7 curriculum by introducing an overarching engineering axiom: “Measurement is critical in our field. In Turkish we say mesura — you cannot manage, optimize, or trust what you cannot rigorously measure.”

  • Generalisation vs Memorization: Training accuracy evaluates fit on seen examples; validation accuracy evaluates true generalization on held-out distributions.
  • Mandatory Validation Conditions: Any reported evaluation metric must document: (1) what exact metric was computed; (2) on which data split it was measured (held-out test set or stratified cross-validation); and (3) what asymmetric error costs govern the real-world domain.
00:30:45 UBIS 00:30:45 to 00:34:30Slides 7–9

Ground Truth (\(y\)) vs Predictions (\(\hat{y}\)) & The Positive Class

Evaluation begins by comparing ground truth against algorithmic inference:

Actual / True Label (\(y\))

  • Slide 7The verified, ground truth class supplied by expert reference or benchmark datasets.
  • Realitye.g., A biopsy-confirmed tumor; a verified legitimate transaction.

Predicted Label (\(\hat{y}\))

  • Slide 7The discrete class label assigned by the machine learning classifier \(f(\mathbf{x})\).

Semantic Definition of the Positive Class: Dr. Bulut stresses that “Positive” is a technical convention, not a moral judgment. It designates the event of interest or the rarer phenomenon being detected — such as “Cancer Present”, “Network Intrusion”, or “Defective Component”.

The Four Fundamental Outcomes & Linguistic Decomposition

A binary classification decision over test instances yields exactly four mutually exclusive outcomes:

OutcomeAdjective (Accuracy)Noun (Prediction)Actual (\(y\))Predicted (\(\hat{y}\))Statistical Alias
True Positive (\(TP\))True (Correct)Positive (\(+1\))Positive (\(+1\))Positive (\(+1\))Hit
True Negative (\(TN\))True (Correct)Negative (\(0\))Negative (\(0\))Negative (\(0\))Correct Rejection
False Positive (\(FP\))False (Incorrect)Positive (\(+1\))Negative (\(0\))Positive (\(+1\))Type I Error (\(\alpha\))
False Negative (\(FN\))False (Incorrect)Negative (\(0\))Positive (\(+1\))Negative (\(0\))Type II Error (\(\beta\))

Dr. Bulut provides a simple mnemonic rule: True / False is the ADJECTIVE (Did the model make the correct judgment?), while Positive / Negative is the NOUN (What did the classifier predict?). For instance, a False Positive means the prediction was Positive, but that prediction was False (incorrect).

2x2 Contingency Matrix & Core Metrics Formulations

Constructing the standard 2x2 grid, marginal sums, Accuracy, Error Rate, and formal definitions of Precision, Recall, and F1 harmonic mean before transitioning to the whiteboard.

00:49:47 UBIS 00:49:47 to 00:53:20Slides 17–24

The 2x2 Contingency Table Architecture

Dr. Bulut introduces the canonical 2x2 confusion matrix grid layout:

Actual \ PredictedPredicted Positive (\(\hat{y}=1\))Predicted Negative (\(\hat{y}=0\))Row Marginals (Ground Truth)
Actual Positive (\(y=1\))\(TP\) (True Positive)\(FN\) (False Negative)\(P = TP + FN\) (Total Actual Positives)
Actual Negative (\(y=0\))\(FP\) (False Positive)\(TN\) (True Negative)\(N = FP + TN\) (Total Actual Negatives)
Column Marginals\(P' = TP + FP\)\(N' = FN + TN\)Total Instances: \(N_{\text{total}} = TP + TN + FP + FN\)

The primary diagonal contains all correct classifications (\(TP + TN\)), while the secondary off-diagonal captures all errors (\(FP + FN\)).

00:53:20 UBIS 00:53:20 to 00:57:01Slides 25–34

Mathematical Formulations: Accuracy, Precision, Recall & F1 Preview

Before closing the first hour, Dr. Bulut outlines the exact mathematical definitions required for the curriculum:

\[\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}, \quad \text{Error Rate} = 1 - \text{Accuracy} = \frac{FP + FN}{TP + TN + FP + FN}\]
\[\text{Precision} (P) = \frac{TP}{TP + FP}, \quad \text{Recall / Sensitivity} (R) = \frac{TP}{TP + FN}\]

Accuracy vs Error Rate Complementarity: Accuracy and Error Rate are strictly complementary: \(\text{Accuracy} + \text{Error Rate} = 1.0\). If a classifier achieves 75% accuracy, its error rate is mathematically guaranteed to be 25%.

Metric NameMathematical DefinitionOperational Interpretation
Accuracy (\(\text{Acc}\))\(\frac{TP + TN}{N_{\text{total}}}\)Overall fraction of correct classifications across all classes.
Error Rate (\(\text{Err}\))\(\frac{FP + FN}{N_{\text{total}}} = 1 - \text{Acc}\)Overall fraction of incorrect decisions.
Precision (\(P\))\(\frac{TP}{TP + FP}\)Factual reliability of positive predictions (minimises false alarms).
Recall (\(R\))\(\frac{TP}{TP + FN}\)Completeness in recovering actual positive cases (minimises missed events).
F1 Score (\(F_1\))\(2 \cdot \frac{P \cdot R}{P + R}\)Harmonic mean balancing precision and recall under class imbalance.

Whiteboard Derivations: Accuracy, Precision, Recall & Specificity

On the whiteboard, Dr. Bulut constructs the corresponding 2x2 contingency matrix:

Actual \ PredictedPredicted PositivePredicted NegativeRow Marginals
Actual Positive\(TP = 3\)\(FN = 1\)\(P = 4\)
Actual Negative\(FP = 1\)\(TN = 3\)\(N = 4\)
Column Marginals\(P' = 4\)\(N' = 4\)\(N_{\text{total}} = 8\)

He executes step-by-step arithmetic derivations live on screen:

\[\text{Accuracy} = \frac{TP + TN}{N_{\text{total}}} = \frac{3 + 3}{8} = \frac{6}{8} = 0.75 \ (75\%)\]
\[\text{Error Rate} = \frac{FP + FN}{N_{\text{total}}} = \frac{1 + 1}{8} = \frac{2}{8} = 0.25 \ (25\%)\]
\[\text{Precision} = \frac{TP}{TP + FP} = \frac{3}{3 + 1} = \frac{3}{4} = 0.75 \ (75\%)\]
\[\text{Recall / Sensitivity} = \frac{TP}{TP + FN} = \frac{3}{3 + 1} = \frac{3}{4} = 0.75 \ (75\%)\]
\[\text{Specificity} = \frac{TN}{TN + FP} = \frac{3}{3 + 1} = \frac{3}{4} = 0.75 \ (75\%)\]

Dr. Bulut intentionally crafted this introductory whiteboard example so that Precision, Recall, and Specificity all equal 75% (\(\frac{3}{4}\)). This allows students to verify the mechanics before encountering asymmetric numbers in multiclass settings.

Constructing the 3x3 Confusion Matrix & Global Accuracy

Dr. Bulut draws the complete 3x3 matrix on the whiteboard (Lecture_07___Confusion_Matrix_.jpg):

Actual \ PredictedCat (\(\hat{y}=1\))Dog (\(\hat{y}=2\))Lion (\(\hat{y}=3\))Actual Totals (Row Sums)
Cat (\(y=1\))3115
Dog (\(y=2\))1416
Lion (\(y=3\))1124
Predicted Totals (Col Sums)564Total: 15

He highlights the Primary Diagonal containing all correct classifications:

\[\sum \text{Diagonal} = 3 \text{ (Cats)} + 4 \text{ (Dogs)} + 2 \text{ (Lions)} = 9 \text{ correct predictions}\]
\[\text{Overall Accuracy} = \frac{\sum \text{Diagonal}}{\text{Total Instances}} = \frac{9}{15} = 0.60 \ (60\%)\]
\[\text{Overall Error Rate} = 1 - \text{Accuracy} = \frac{15 - 9}{15} = \frac{6}{15} = 0.40 \ (40\%)\]

Row Sums (Ground Truth Totals)

  • Cat Row\(3 + 1 + 1 = 5\) true cats in dataset.
  • Dog Row\(1 + 4 + 1 = 6\) true dogs in dataset.
  • Lion Row\(1 + 1 + 2 = 4\) true lions in dataset.

Column Sums (Model Predictions)

  • Cat Col\(3 + 1 + 1 = 5\) predictions for Cat.
  • Dog Col\(1 + 4 + 1 = 6\) predictions for Dog.
  • Lion Col\(1 + 1 + 2 = 4\) predictions for Lion.

In any \(K \times K\) confusion matrix, global accuracy is always the trace of the matrix (sum of main diagonal elements) divided by the total sum of all cells. All non-diagonal entries represent misclassifications between specific class pairs.

To evaluate individual class performance, Dr. Bulut asks the class to pick a target animal: they choose Lion. He demonstrates how to collapse the 3x3 matrix into a 2x2 binary problem for Lion vs Non-Lion:

01:29:41 GMeet 00:32:45 to 00:37:00Board Pt 3

Lion Precision, Recall & F1 Harmonic Mean Mathematical Proof

Using the isolated values, Dr. Bulut computes class-specific metrics for Lion:

\[\text{Precision}_{\text{Lion}} = \frac{TP}{TP + FP} = \frac{2}{2 + 2} = \frac{2}{4} = 0.50 \ (50\%)\]
\[\text{Recall}_{\text{Lion}} = \frac{TP}{TP + FN} = \frac{2}{2 + 2} = \frac{2}{4} = 0.50 \ (50\%)\]

He then derives the F1 Score Harmonic Mean on the whiteboard:

\[F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2 \cdot 0.50 \cdot 0.50}{0.50 + 0.50} = \frac{0.50}{1.00} = 0.50\]
NOTICE · WHY HARMONIC MEAN IS PENALIZING GMeet 00:36:39 · Mathematical Proof

Dr. Bulut asks: Why don't we just take the simple arithmetic mean \(\frac{P + R}{2}\)? Because the arithmetic mean hides severe failures! If a model predicts everything as positive, it could achieve \(Recall = 1.0\) and \(Precision = 0.05\); its arithmetic mean would be \(\approx 0.525\), masking complete failure. The harmonic mean is governed by reciprocals: \(\frac{1}{F_1} = \frac{1}{2}(\frac{1}{P} + \frac{1}{R})\). If either metric approaches zero, \(F_1\) crashes to zero!
